账号管理

维护后台账号、姓名、角色、启用状态和密码，账号不与取货点关联。

1列表字段

筛选：用户账号输入框模糊匹配登录账号。
筛选：用户名称输入框模糊匹配姓名。
筛选：角色下拉选择角色。
筛选：状态全部状态、启用、停用。
用户账号展示后台登录账号。
用户名称展示账号姓名。
角色展示账号绑定的角色名称。
创建时间展示账号创建时间，精确到时分秒。
状态启用 / 停用。
操作编辑、重置密码、禁用或启用。

2状态 / 操作

启用可编辑、重置密码、禁用。
停用可编辑、启用；禁止登录。

3关联记录

角色权限账号功能和可操作按钮由角色决定。
登录会话停用或重置密码后原会话失效。
最后管理员保护不能停用最后一个具备后台管理能力的账号。

4操作说明

查询 / 重置按用户账号、用户名称、角色和状态筛选。
新增 / 编辑保存账号基础信息和角色。
重置密码核对目标账号后设置新的登录密码。
启用 / 禁用二次确认后切换，禁止突破最后管理员约束。
当前页面：账号管理 · 列表字段 → 状态 / 操作 → 关联记录 → 操作说明

后台弹窗 PRDACCOUNT

新增 / 编辑运营账号

维护后台账号的用户名称、用户账号、角色和密码，账号不与取货点关联。

1必填项（填写说明）

用户名称必填，1–30 字。
用户账号必填，3–30 位且唯一。
角色必填，选择一个可授予角色。
初始密码新增账号必填，编辑时选填；8–64 位。

2状态 / 操作

新增保存后默认启用。
编辑保存后更新账号信息。
校验失败提示用户账号重复或字段错误。

3详情字段

用户名称账号显示名称。
用户账号后台登录账号。
角色决定账号可见菜单和操作权限。
初始密码8–64 位。

4关联记录

角色账号功能由角色决定。
登录会话角色或密码变化后会话失效。

5操作说明

保存校验用户名称、用户账号、角色和密码后新增或更新。
取消 / 关闭不保存修改。

重置账号密码

新密码和再次输入密码。 右侧同步展示弹窗 PRD。

后台弹窗 PRDRESET-PASSWORD

重置登录密码

为指定后台账号设置新的登录密码并强制其重新登录。

1必填项（填写说明）

用户账号只读，由目标账号带入。
用户名称只读，由目标账号带入。
重置为必填，8–64 位。

2状态 / 操作

可提交输入符合长度的新密码后保存。
校验失败提示密码长度错误。
重置成功关闭弹窗并失效目标账号会话。

3详情字段

用户账号由当前操作行决定，不允许改写。
用户名称由当前操作行决定，不允许改写。

4关联记录

账号新密码写回后台账号。
登录会话账号登录版本更新。

5操作说明

确认重置校验后保存新密码。
取消 / 关闭不修改密码。

3详情字段

4关联记录

业务记录确认后写入对应业务数据。

5操作说明

确认执行当前操作。

提示文案

按钮反馈、校验错误、空状态和业务拦截提示。

账号重复：账号已存在
密码长度错误：初始密码为 8–64 位
两次密码不一致：两次密码不一致
停用确认：停用后当前会话失效
最后管理员保护：至少保留一个启用且能管理账号和角色的账号
