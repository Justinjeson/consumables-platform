库存管理

在固定取货点查看账面库存、订单占用和可销售量，并执行新增入库。

1列表字段

筛选：商品名称输入框模糊匹配商品名称。
筛选：商品规格下拉选择，选项来自商品规格字典明细。
筛选：商品分类下拉选择，选项来自商品分类字典明细。
筛选：库存状态有可售库存 / 无可售库存。
商品商品名称和规格。
账面库存实物库存数量。
订单占用未完成订单已占用数量。
可销售量账面库存减订单占用，不得为负。
状态有可售库存 / 无可售库存。

2状态 / 操作

有可售库存商品可正常购买。
无可售库存不可售，需补货。

3关联记录

商品主数据库存按商品编码关联 商品管理 商品。
订单占用待支付和待取货订单占用库存。
入库记录新增入库累加账面库存并保留说明。
核销扣减核销完成后扣减账面库存和订单占用。

4操作说明

查询 / 重置按名称、规格、商品分类和库存状态筛选。
导入入库上传 CSV/TXT，按商品编码批量增加入库数量。
新增入库单条录入商品、数量和备注后累加账面库存。
当前页面：库存管理 · 列表字段 → 状态 / 操作 → 关联记录 → 操作说明

弹窗与关键状态

本模块相关弹窗、确认框、校验状态和结果页统一汇总于此；有独立 PRD 的状态直接完整展示。

导入入库预览

按商品编码和入库数量逐行校验，确认后批量累加库存。 右侧同步展示弹窗 PRD。

后台弹窗 PRDSTOCK-IMPORT

导入入库

按商品编码批量导入当前固定取货点的入库数量。

1必填项（填写说明）

导入文件必填，CSV/TXT，不超过 2 MB。
商品编码必填，必须是当前存在的 SP + 7 位商品编码。
入库数量必填，1–1,000,000 的整数。
入库备注选填，最多 200 字。

2状态 / 操作

未上传可下载模板和选择文件。
校验通过允许确认导入入库。
存在错误行禁止导入并展示逐行错误。

3详情字段

固定取货点库存统一增加到当前固定取货点。
库存累加确认后按商品逐行累加账面库存，并刷新可销售量。

4关联记录

商品通过商品编码关联商品主数据。
库存更新账面库存和库存版本。
入库记录按商品记录本次入库数量和备注。

5操作说明

下载模板下载库存导入 CSV 模板。
选择文件解析并校验商品编码、数量和备注。
确认导入入库全部校验通过后一次性提交。
取消 / 关闭不改变库存。
当前弹窗：导入入库 · 必填项（填写说明） → 状态 / 操作 → 详情字段 → 关联记录 → 操作说明
新增库存入库

商品、入库数量和入库备注。 右侧同步展示弹窗 PRD。

后台弹窗 PRDSTOCK

新增库存入库

为当前固定取货点商品增加账面库存。

1必填项（填写说明）

商品必填。
数量必填整数；入库必须大于 0。
原因登记盘亏和复盘校正必填，新增入库选填。

2状态 / 操作

可入库填写数量和备注。
校验失败提示数量非法或库存版本冲突。
保存成功累加账面库存并刷新列表。

3详情字段

账面库存当前账面数量。
订单占用未完成订单占用数量。
可销售量账面库存减订单占用。

4关联记录

商品库存关联商品主数据。
订单订单占用参与可售量计算。
库存变更记录入库数量和备注。

5操作说明

确认入库校验库存版本与数量后保存。
取消 / 关闭不改变库存。
当前弹窗：新增库存入库 · 必填项（填写说明） → 状态 / 操作 → 详情字段 → 关联记录 → 操作说明
入库成功提示

库存保存后的成功轻提示。

提示文案

按钮反馈、校验错误、空状态和业务拦截提示。

库存更新：库存已更新
库存冲突：库存已更新，请关闭后重新打开
数量非法：请填写有效整数数量
入库备注最多 200 字
导入错误：有 N 行校验未通过，请修正文件后重新导入
