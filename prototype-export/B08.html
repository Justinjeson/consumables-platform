角色权限

在角色列表中选择角色，并在右侧按模块配置可访问菜单和可执行操作，保存后关联账号立即生效。

1列表字段

角色与权限左侧展示角色名称、角色描述和关联账号数。
角色点击切换右侧当前配置角色。
关联账号只读展示当前角色绑定的账号人数。
权限配置右侧按模块展示查看和操作权限。
已选项实时统计当前角色已勾选的权限数量。

2状态 / 操作

可编辑角色可编辑角色资料、全选、清空、保存和删除未关联角色。
已关联账号可编辑和保存，不允许删除。
无修改权限只展示当前权限配置，不提供保存和批量操作。

3关联记录

关联账号角色被账号引用后不可删除。
菜单权限决定账号可见页面。
操作权限决定账号按钮可见性和后端操作校验。
权限变更保存后关联账号即时生效。

4操作说明

选择角色切换左侧角色并刷新右侧权限配置。
新增 / 编辑资料维护角色名称和角色描述。
全选 / 清空批量勾选或取消当前操作者可授予的全部权限。
保存校验菜单与操作权限、授权范围和最后管理员约束后保存。
删除角色仅未关联账号的角色可删除。
当前页面：角色权限 · 列表字段 → 状态 / 操作 → 关联记录 → 操作说明

编辑角色资料

后台弹窗 PRDROLE-PROFILE

新增 / 编辑角色资料

维护角色名称和角色描述；权限在角色权限页面右侧配置。

1必填项（填写说明）

角色名称必填，1–30 字且唯一。
角色描述选填，最多 200 字。

2状态 / 操作

新增创建角色并使用当前勾选的权限。
编辑更新角色名称和描述，权限保持不变。
校验失败提示角色名称重复或字段错误。

3详情字段

角色名称角色在列表和账号绑定中展示的名称。
角色描述用于说明岗位或用途。

4关联记录

角色权限权限在角色权限页面右侧维护。
关联账号角色名称更新后，账号管理同步展示新名称。

5操作说明

保存资料校验名称唯一性并保存。
取消 / 关闭不保存修改。
