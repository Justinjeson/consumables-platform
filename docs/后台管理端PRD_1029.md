# 汇元包装耗材平台｜后台管理端 P0 产品需求文档

- 文档编号：HC-ADMIN-PRD-1029
- 版本：v2.0
- 日期：2026-10-29
- 适用范围：管理后台 P0
- 文档结构：按「统计卡 → 列表字段 → 状态 / 操作 → 详情字段 → 关联记录 → 操作说明」组织；无统计卡或无关联记录的模块直接省略对应段，不展示空占位。

> 本文件与后台原型右侧 PRD 使用同一份数据源生成。后台原型中的页面 PRD 可直接随菜单切换查看；本文件用于评审、开发和测试归档。小程序页面 PRD 仍以用户端右侧面板为准。

## 0. 通用规则

1. 后台采用左侧模块导航、中间业务内容、右侧页面 PRD 的布局；PRD 可隐藏和重新打开。
2. 当前固定取货点为「元谋一号取货点」，后台不提供取货点切换。
3. 列表默认每页 10 条，可选 10 / 20 / 50 条；查询后回到第 1 页。
4. 金额保留 2 位小数，时间格式为 `YYYY/MM/DD HH:mm:ss`，空值统一显示“—”。
5. 账号只绑定角色，不与取货点关联；后台查询和操作权限由角色控制。
6. 按钮按权限显示，后端仍需再次校验权限。
7. 所有保存操作必须有成功或失败提示；失败时保留弹窗和用户输入。
8. P1 的取消与退款、核销记录与对账、退款审核、销售统计不进入当前后台范围。
9. 订单记录只展示订单编号、创建时间、付款时间、核销/确认收货时间；不展示订单状态、核销方式、操作时间线或商户交易号。
10. 不提供「重置数据」入口；退出登录不清空业务数据。

## 1. B04 订单管理

**页面目标：** 查询权限范围内订单，查看订单记录与商品明细，并对待取货订单完成扫码或输码核销。

### 统计卡

| 项目 | 说明 |
|---|---|
| 全部订单 | 当前查询条件下待支付、待取货和已完成订单总数。 |
| 待支付 | 当前查询条件下待支付订单数。 |
| 待取货 | 当前查询条件下待取货订单数。 |
| 已完成 | 当前查询条件下已完成订单数。 |

### 列表字段

| 项目 | 说明 |
|---|---|
| 筛选：订单号 | 输入框模糊匹配当前订单号和历史订单号。 |
| 筛选：联系人 | 输入框模糊匹配联系人和联系电话。 |
| 筛选：创建日期 | 开始日期至结束日期，闭区间。 |
| 订单 / 商品 | 订单号加粗，副行展示商品名称和数量。 |
| 联系人 / 取货点 | 主行联系人，副行取货点。 |
| 金额 | 订单合计，保留 2 位小数。 |
| 当前状态 | 待支付、待取货、已完成。 |
| 创建时间 | 精确到时分秒，默认倒序展示。 |
| 操作 | 详情、核销，按状态和权限显示。 |

### 状态 / 操作

| 项目 | 说明 |
|---|---|
| 待支付 | 查看详情；不显示核销。 |
| 待取货 | 查看详情、查看支付账单、扫码核销。 |
| 已完成 | 查看详情、查看支付账单。 |

### 详情字段

| 项目 | 说明 |
|---|---|
| 订单号 | DD + 日期 + 6 位流水号，只读。 |
| 操作人 | 展示当前环节操作人：下单用户或核销账号。 |
| 联系人 / 电话 | 订单快照，展示完整联系电话。 |
| 取货点 | 订单快照中的取货点名称和地址。 |
| 订单金额 | 保留 2 位小数。 |
| 商品明细 | 商品名称、规格、单价、数量、金额。 |
| 订单记录 | 展示订单编号、创建时间、付款时间、核销/确认收货时间，时间均精确到时分秒。 |

### 关联记录

| 项目 | 说明 |
|---|---|
| 商品明细 | 来自订单商品快照，不随商品后续修改而变化。 |
| 支付账单 | 已支付订单可查看，展示支付方式、商户订单号、支付时间和取货点。 |
| 库存占用 | 待支付和待取货订单占用库存；核销完成后扣减，未完成订单保持占用。 |
| 核销结果 | 核销完成后写入核销/确认收货时间。 |

### 操作说明

| 项目 | 说明 |
|---|---|
| 查询 / 重置 | 刷新统计卡、状态标签和列表，重置后回到第 1 页。 |
| 扫码核销 | 打开核销弹窗，扫码或输入 8 位核销码/订单号查询。 |
| 查看详情 | 只读查看订单字段、商品明细和三个订单记录时间。 |
| 核销交货 | 核对商品与数量后确认，重复核销必须拦截。 |

| 项目 | 说明 |
|---|---|

## 8. 后台弹窗 PRD

## 1. PASSWORD 修改密码

**弹窗目标：** 校验原密码后修改当前后台账号密码，并强制重新登录。

### 列表字段

| 项目 | 说明 |
|---|---|
| 原密码 | 必填，用于校验当前账号。 |
| 新密码 | 必填，8–64 位。 |
| 确认新密码 | 必填，必须与新密码一致。 |

### 状态 / 操作

| 项目 | 说明 |
|---|---|
| 可编辑 | 显示三个密码输入框。 |
| 校验失败 | 提示原密码错误、长度不合法或两次密码不一致。 |
| 保存成功 | 关闭弹窗、退出原会话并回到登录页。 |

### 详情字段

| 项目 | 说明 |
|---|---|
| 密码规则 | 新旧密码均为 8–64 位；新密码不能与原密码相同。 |
| 会话处理 | 修改成功后原会话立即失效。 |

### 关联记录

| 项目 | 说明 |
|---|---|
| 当前账号 | 只修改当前账号，不允许选择其他账号。 |
| 登录会话 | 密码修改后重新登录。 |

| 项目 | 说明 |
|---|---|

## 2. PICKUP 取货核销

**弹窗目标：** 扫码或输入 8 位核销码/订单号查询待取货订单，核对商品后确认交货。

## 9. 验收标准

- [ ] 后台七个页面均能在原型中打开对应页面 PRD。
- [ ] 页面 PRD 按实际内容展示：有统计卡才显示统计卡，有关联记录才显示关联记录，其余段落顺序不变。
- [ ] 菜单切换后，右侧 PRD 标题和内容同步切换。
- [ ] 查询、重置、分页、弹窗、校验和权限规则与页面一致。
- [ ] 订单记录只展示订单编号和三个实际时间字段。
- [ ] 商品、库存、账号、角色和字典的关联记录说明与页面数据关系一致。
- [ ] 后台不出现 P1 入口或文档外字段。
